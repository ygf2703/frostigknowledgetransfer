---
name: weekly-report
description: Write a weekly status report in a fixed structure.
---

Use this skill when the user asks for a weekly report.

Inputs to collect (ask once, together, if missing): the week's achievements, open items, next week's plan, and the audience (manager or client).

Process:
1. Open with a two-sentence summary: state of the week and the single most important thing to know.
2. Achievements as bullets, each with a fact (number, deliverable, date).
3. Open items with an owner per item; next steps with a real date per step.
4. For a client audience, drop internal jargon and add one line on what you need from them.

Output: a one-page report in the fixed structure above.

Boundaries: no superlatives, no invented progress. If an item was not provided, write "טרם עודכן" instead of guessing.

Before presenting, check: every open item has an owner, every next step has a date, and the summary matches the bullets.

Example - a marketing project manager sends a client: "השבוע: עלתה קמפיין החורף (3 ערוצים), אושרו 5 מודעות. פתוח: חומרי וידאו - לקוח, עד 29.10. בשבוע הבא: דוח ביצועים ראשון ב-3.11."

ab-test-readקריאת תוצאות מבחן A/B בלי מסקנות שווא▾ הועתק ✓ 
---
name: ab-test-read
description: Read A/B test results with unit-of-analysis, denominator and maturity checks.
---

Use this skill when the user shares A/B test results.

Inputs to collect: the metric per variant, sample size per variant, the primary metric decided before the test, and how users were assigned.

Process:
1. Check the unit of independence: if the same user appears in both variants or many times in one, per-pageview numbers overstate the evidence. Flag it.
2. Check denominators: conversion of what - visitors, sessions, clicks?
3. Check maturity: was the test stopped at a planned point or peeked at until it looked good? Early wins regress.
4. Compute the significance calculation from the counts, or request the success counts if they are missing. Without a calculation, no winner can be declared - state that as a limitation, not as a verdict.

Output: the evidence summary, what can and cannot be concluded, and the options (ship / iterate / drop / keep running) - "keep running" only after the design checks above pass, and only up to the planned sample, not beyond it.

Boundaries: never declare a winner from raw percentages alone. There is no universal minimum test length - maturity depends on traffic, effect size, and cycles of the business.

Before presenting, check: the conclusion follows from the computed evidence, not from the direction the user hoped for.

Example - a signup-button test: A = 96 signups / 1,200 visitors (8.0%), B = 105 / 1,180 (8.9%). Independence and denominators check out, but the difference is about z=0.78 - not significant at common levels. Conclusion: with this data no winner can be declared. If the design is sound and the planned sample has not been reached, the option is to continue to the plan; if it has, the honest verdict is no detectable difference.

Use this skill when the user asks for a landing page with nostalgia and groove - music, food, community events, a brand with a wink to the past.

Inputs to collect (ask once, together, if missing): the one action the page wants, the content, photos with warm tones if available, and a logo file if the page carries one.

Design language:
- Palette: cream #F6E8D4, burnt orange #C2571B, mustard #D9A441, avocado green #5B7553, dark brown #3E2A1E for text.
- Type: a fat rounded display face (Hebrew: a bold rounded sans; Latin: Cooper Black style or Recoleta), body in a warm sans. Headlines can arc along a curve.
- Layout: concentric rainbow arcs, sun-ray bursts behind the hero, wavy section dividers, everything centered and chunky. Photos in arch-shaped frames.
- Logo treatment: the logo set inside a retro badge - a circle with a ring border, like an embroidered patch - or watermarked faintly (6-8% opacity) between the wave dividers at varying sizes.

Process:
1. Open with a sun-ray burst behind the headline, arced if the word is short.
2. Alternate cream and mustard sections, divided by fat waves.
3. Frame photos in arches; badge the prices or dates in ringed circles.
4. The call to action is a burnt-orange pill with a thick brown outline.

Output: the page built in this language, with the real content in place.

Boundaries: stay in the four-color palette - no modern neons, no pure black. Chunky and warm, never thin. Gradients only as flat rainbow arcs.

Before presenting, check: the palette stays in the seventies, every wave and arc is smooth, and the page feels like a warm record sleeve, not a costume.

Example - a vinyl fair page: "יריד התקליטים" arced over a mustard sun, stalls in arch frames, a burnt-orange button: "לפרטים ולכרטיסים".
